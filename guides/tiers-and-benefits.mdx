## Tier System

Users progress through tiers based on their **lifetime earned** points. Higher tiers unlock better point multipliers and exclusive benefits.

| Tier | Lifetime points | Earn multiplier | Example Benefits |
|------|----------------|-----------------|-----------------|
| Bronze | 0 | 1.0x | Base rewards access |
| Silver | 5,000 | 1.25x | Priority cashback, bonus points |
| Gold | 20,000 | 1.5x | Exclusive catalog items, higher cashback rates |
| Platinum | 50,000 | 2.0x | VIP access, maximum cashback rates, early access |

The multiplier applies to **earning**. Redemption is a flat rate for every tier —
see [Order redemption](/guides/order-redemption).

<Note>
  Tier thresholds and multipliers are configurable by mgPass operators (requires the `mgpass:admin` scope). The values above are defaults.
</Note>

## Promotion

Tier promotion is **automatic**. After every point credit, the engine checks:

```
if (lifetime_earned >= next_tier.min_points) → promote
```

- Promotion is immediate -- the next event uses the new multiplier
- **Tiers never go down.** A tier you have reached is yours. If an operator
  raises a threshold above where you already sit, you keep the tier you earned —
  the new threshold applies only to people who have not reached it yet
- Users are notified via webhook event `rewards.tier_promoted`
- Tier status is included in the user's JWT claims for downstream apps

## Important: Lifetime vs Balance

| Metric | Used For |
|--------|----------|
| `lifetime_earned` | Tier calculation -- only goes up |
| `total_points` | Spending balance -- goes up and down |

Redeeming points reduces `total_points` but does **not** affect `lifetime_earned`. A user who earned 25,000 points and spent 20,000 still qualifies for Gold tier.

## Benefits

Benefits are predefined perks attached to tiers:

| Type | Description | Example |
|------|-------------|---------|
| `toggle` | On/off feature access | "Priority Support" |
| `multiplier` | Numeric multiplier | "2x points on weekends" |
| `discount` | Percentage discount | "10% off partner purchases" |
| `access` | Exclusive content/features | "Early access to new rewards" |
| `custom` | Freeform benefit | "Birthday bonus: 500 points" |

Benefits are managed in the developer console and assigned to tiers via checkboxes.
