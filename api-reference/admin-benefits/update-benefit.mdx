---
title: "Update Benefit"
api: "PATCH /api/rewards/benefits/{id}"
---

Updates a tier benefit. Only the fields you send are changed.

Requires an admin bearer token.

## Path parameters

<ParamField path="id" type="string" required />

## Body

<ParamField body="id" type="string" />

<ParamField body="tier" type="string" />

<ParamField body="title" type="string" />

<ParamField body="description" type="string" />

<ParamField body="icon" type="string" />

<ParamField body="is_active" type="boolean" />

## Response

<ResponseField name="id" type="string" />

<ResponseField name="tier" type="string" />

<ResponseField name="title" type="string" />

<ResponseField name="description" type="string" />

<ResponseField name="icon" type="string" />

<ResponseField name="is_active" type="boolean" />

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | No updatable fields were sent. |
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `not_found` | No benefit with that id. |
