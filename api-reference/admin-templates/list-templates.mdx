---
title: "List Templates"
api: "GET /api/templates"
---

Every notification template — the email and SMS bodies the platform sends.

Requires an admin bearer token.

## Query parameters

<ParamField query="channel" type="string">
  One of `email`, `sms`, `in_app`.
</ParamField>

<ParamField query="event_type" type="string" />

## Response

An array of items.

<ResponseField name="id" type="string" />

<ResponseField name="event_type" type="string" />

<ResponseField name="channel" type="string">
  One of `email`, `sms`, `in_app`.
</ResponseField>

<ResponseField name="locale" type="string" default="en" />

<ResponseField name="subject" type="string">
  Email only.
</ResponseField>

<ResponseField name="body" type="string" />

<ResponseField name="is_active" type="boolean" />

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |
