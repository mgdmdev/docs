---
title: "Update Template"
api: "PATCH /api/templates/{id}"
---

Updates a notification template. Only the fields you send are changed.

Requires an admin bearer token.

<Warning>
  A template goes live on the next send. There is no draft state and no preview — a broken variable reaches real inboxes immediately.
</Warning>

## Path parameters

<ParamField path="id" type="string" required />

## Body

<ParamField body="id" type="string" />

<ParamField body="event_type" type="string" />

<ParamField body="channel" type="string">
  One of `email`, `sms`, `in_app`.
</ParamField>

<ParamField body="locale" type="string" default="en" />

<ParamField body="subject" type="string">
  Email only.
</ParamField>

<ParamField body="body" type="string" />

<ParamField body="is_active" type="boolean" />

## Response

<ResponseField name="id" type="string" />

<ResponseField name="event_type" type="string" />

<ResponseField name="channel" type="string">
  One of `email`, `sms`, `in_app`.
</ResponseField>

<ResponseField name="locale" type="string" default="en" />

<ResponseField name="subject" type="string">
  Email only.
</ResponseField>

<ResponseField name="body" type="string" />

<ResponseField name="is_active" type="boolean" />

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `no_fields` | No valid fields to update. |
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `not_found` | No template with that id. |
