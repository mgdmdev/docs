---
title: "Create Organization"
api: "POST /api/organizations"
---

Creates an organization. Applications and users are attached to it afterwards.

Requires an admin bearer token.

## Body

<ParamField body="id" type="string" />

<ParamField body="name" type="string" />

<ParamField body="slug" type="string" />

<ParamField body="logo_url" type="string" />

<ParamField body="created_at" type="string" />

## Response

<ResponseField name="id" type="string" />

<ResponseField name="name" type="string" />

<ResponseField name="slug" type="string" />

<ResponseField name="logo_url" type="string" />

<ResponseField name="created_at" type="string" />

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | `name` is missing. |
| 401 | `unauthorized` | Missing or invalid admin token. |
