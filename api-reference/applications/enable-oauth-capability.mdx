---
title: "Enable OAuth capability"
description: "Add the OAuth capability row to an application. For confidential clients, returns the client_secret once."
api: "POST /api/applications/{id}/capabilities/oauth"
---

Adds the `application_oauth` row that turns this application into a usable OAuth client. For `web` and `m2m` clients, mgPass generates and bcrypt-hashes a `client_secret`, then returns the plaintext value exactly **once** in this response. SPA and native clients use `none` (PKCE-only) and do not receive a secret.

Requires an admin bearer token with the `applications:write` scope.

<Warning>
The `client_secret` field is only returned by this call and by `rotate-oauth-secret`. Store it in your secret manager immediately; mgPass cannot recover it later.
</Warning>

## Path parameters

<ParamField path="id" type="string" required>
  Application ID, e.g. `app_3news`.
</ParamField>

## Body

<ParamField body="client_type" type="string" required>
  One of `web`, `spa`, `native`, or `m2m`. Determines whether a `client_secret` is issued and what the default `auth_methods` look like.
</ParamField>

<ParamField body="redirect_uris" type="string[]">
  Allowed `redirect_uri` values for authorization code flows. Default `[]`.
</ParamField>

<ParamField body="post_logout_uris" type="string[]">
  Allowed `post_logout_redirect_uri` values for end-session flows. Default `[]`.
</ParamField>

<ParamField body="allowed_scopes" type="string[]" default="['openid', 'profile', 'email']">
  Scopes this client is allowed to request.
</ParamField>

<ParamField body="cors_origins" type="string[]">
  Browser origins permitted to call OAuth and userinfo endpoints with credentials.
</ParamField>

<ParamField body="access_token_ttl" type="integer">
  Access-token lifetime in seconds.
</ParamField>

<ParamField body="refresh_token_ttl" type="integer">
  Refresh-token lifetime in seconds.
</ParamField>

<ParamField body="refresh_token_rotation" type="boolean" default="true">
  Rotate refresh tokens on every refresh.
</ParamField>

<ParamField body="auth_methods" type="string[]">
  Token-endpoint authentication methods. Defaults to `['none']` for `spa`/`native`, `['client_secret_basic', 'client_secret_post']` for `web`/`m2m`.
</ParamField>

<ParamField body="access_control" type="object">
  Optional JSON access policy (e.g. role/audience restrictions).
</ParamField>

<ParamField body="custom_subdomain" type="string">
  Custom auth subdomain on the `mgpass.net` zone (e.g. `auth.3news.com` aliased through us).
</ParamField>

<ParamField body="custom_domain" type="string">
  Custom apex/auth domain pointing at mgPass.
</ParamField>

## Response

Returns `201 Created` with the new capability row plus the `client_secret` (confidential clients only).

<ResponseField name="application_id" type="string">
  Echo of the application ID.
</ResponseField>

<ResponseField name="client_type" type="string">
  The client type you set.
</ResponseField>

<ResponseField name="client_secret" type="string">
  Plaintext secret. Only present for `web` and `m2m`. Shown once.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | Missing or invalid `client_type`. |
| 404 | `not_found` | Unknown application ID. |
| 409 | `capability_exists` | OAuth capability is already enabled. Use `PATCH` instead. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "client_type": "web",
    "redirect_uris": ["https://3news.com/auth/callback"],
    "post_logout_uris": ["https://3news.com/logged-out"],
    "allowed_scopes": ["openid", "profile", "email", "offline_access"]
  }'
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${adminToken}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      client_type: "web",
      redirect_uris: ["https://3news.com/auth/callback"],
      post_logout_uris: ["https://3news.com/logged-out"],
      allowed_scopes: ["openid", "profile", "email", "offline_access"],
    }),
  }
);
const { client_secret } = await res.json();
// Persist client_secret now — it is not retrievable later.
```
