---
title: "Get application"
description: "Fetch a spine row joined with its capability rows and webhook count."
api: "GET /api/applications/{id}"
---

Returns the application spine, its three capability rows (`oauth`, `rewards`, `subscriptions` — each `null` if not enabled), and the number of webhooks registered against it. Sensitive hashes (`client_secret_hash`, `api_key_hash`) are stripped from the response.

Requires an admin bearer token with the `applications:read` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Application ID, e.g. `app_3news`.
</ParamField>

## Response

<ResponseField name="application" type="object">
  The spine row (id, slug, name, branding, support contacts, organization_id, is_active, timestamps).
</ResponseField>

<ResponseField name="capabilities" type="object">
  Object with `oauth`, `rewards`, and `subscriptions` keys. Each value is the capability row or `null`.
</ResponseField>

<ResponseField name="webhooks_count" type="integer">
  Number of webhooks registered against this application.
</ResponseField>

<CodeGroup>

```bash curl
curl -X GET "https://auth.mgpass.net/api/applications/app_3news" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/applications/app_3news", {
  headers: { Authorization: `Bearer ${adminToken}` },
});
const { application, capabilities, webhooks_count } = await res.json();
```

</CodeGroup>

```json
{
  "application": {
    "id": "app_3news",
    "slug": "3news",
    "name": "3News",
    "is_active": 1
  },
  "capabilities": {
    "oauth": {
      "application_id": "app_3news",
      "client_type": "web",
      "redirect_uris": "[\"https://3news.com/auth/callback\"]"
    },
    "rewards": null,
    "subscriptions": {
      "application_id": "app_3news",
      "entitlement_jwt_mode": "plan_status",
      "is_active": 1
    }
  },
  "webhooks_count": 2
}
```
