---
title: "Rotate webhook secret"
description: "Issue a new raw HMAC signing key for a webhook. Returns the plaintext value once."
api: "POST /api/applications/{id}/webhooks/{webhookId}/rotate-secret"
---

Generates a new 32-character raw HMAC `secret` and stores it as-is — the dispatcher signs outgoing payloads with the raw value, so it is not hashed. The previous secret is invalidated immediately. Update your receiver before signatures with the new key start landing.

Requires an admin bearer token with the `applications:write` scope.

<Warning>
The plaintext `secret` is only returned here. Roll it into your secret manager and load it into your webhook receiver before invalidating the old one in your verification logic.
</Warning>

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

<ParamField path="webhookId" type="string" required>
  Webhook ID.
</ParamField>

## Response

<ResponseField name="application_id" type="string">
  Echo of the application ID.
</ResponseField>

<ResponseField name="webhook_id" type="string">
  Echo of the webhook ID.
</ResponseField>

<ResponseField name="secret" type="string">
  The new raw HMAC signing key. Shown once.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Webhook does not exist or does not belong to this application. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/applications/app_mgtix/webhooks/whk_01HXYZ/rotate-secret" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

