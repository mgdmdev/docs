---
title: "Disable subscriptions capability"
description: "Remove the subscriptions capability row from an application."
api: "DELETE /api/applications/{id}/capabilities/subscriptions"
---

Deletes the `application_subscriptions` row. Inbound tenant `/v1/*` calls authenticated with this application's `api_key` start failing with `401`. Existing subscriptions, invoices, and renewal queue entries remain in place so support can continue to resolve open billing cases.

Requires an admin bearer token with the `applications:write` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` when the capability row was removed.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Subscriptions capability is not enabled for this application. |

<CodeGroup>

```bash curl
curl -X DELETE "https://auth.mgpass.net/api/applications/app_mgtix/capabilities/subscriptions" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
await fetch(
  "https://auth.mgpass.net/api/applications/app_mgtix/capabilities/subscriptions",
  { method: "DELETE", headers: { Authorization: `Bearer ${adminToken}` } }
);
```

</CodeGroup>
