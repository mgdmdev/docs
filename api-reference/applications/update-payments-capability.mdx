---
title: "Update payments capability"
description: "Change settlement mode, channels or the default platform fee."
api: "PATCH /api/applications/{id}/capabilities/payments"
---

Changes how an existing Payments capability behaves. Only the fields you send are changed.

Requires an admin bearer token.

<Note>
  Switching to `settlement_mode: destination` is refused unless a default destination already exists or one is supplied alongside. The mode and the destination move together, or the Application is left able to charge with nowhere to settle.
</Note>

## Path parameters

<ParamField path="id" type="string" required />

## Body

<ParamField body="settlement_mode" type="string">
  One of `destination`, `per_payment`, `platform`.
</ParamField>

<ParamField body="default_platform_fee" type="integer" />

<ParamField body="allowed_channels" type="array" />

<ParamField body="statement_descriptor" type="string" />

<ParamField body="is_active" type="boolean" />

## Response

The updated capability.

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `no_fields` | No updatable fields were sent. |
| 400 | `payout_destination_required` | Switching to `destination` with none available. |
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `not_found` | Payments capability not enabled for this Application. |
