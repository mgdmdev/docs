---
title: "Get webhook"
description: "Fetch a single webhook config. Raw signing secret is masked."
api: "GET /api/applications/{id}/webhooks/{webhookId}"
---

Returns one webhook config attached to an application. The `webhook_secret` field is masked as `"****"` — raw secrets are only returned at create or rotate time.

Requires an admin bearer token with the `applications:read` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

<ParamField path="webhookId" type="string" required>
  Webhook ID, e.g. `whk_01HXYZ...`.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Webhook ID.
</ResponseField>

<ResponseField name="application_id" type="string">
  Owning application.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable name.
</ResponseField>

<ResponseField name="endpoint_url" type="string">
  Destination URL.
</ResponseField>

<ResponseField name="event_types" type="string">
  JSON-encoded array of subscribed event types.
</ResponseField>

<ResponseField name="is_active" type="integer">
  `1` for active, `0` for paused.
</ResponseField>

<ResponseField name="webhook_secret" type="string">
  Always `"****"` in this view.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Webhook does not exist or does not belong to this application. |

<CodeGroup>

```bash curl
curl -X GET "https://auth.mgpass.net/api/applications/app_mgtix/webhooks/whk_01HXYZ" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/applications/app_mgtix/webhooks/whk_01HXYZ",
  { headers: { Authorization: `Bearer ${adminToken}` } }
);
const webhook = await res.json();
```
