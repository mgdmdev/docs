---
title: "Rotate OAuth client secret"
description: "Issue a new client_secret for a confidential OAuth client. Returns the plaintext value once."
api: "POST /api/applications/{id}/capabilities/oauth/rotate-secret"
---

Generates a new `client_secret`, bcrypt-hashes it server-side, and returns the plaintext value **once**. The previous secret is invalidated immediately — existing access and refresh tokens stay valid until they expire, but `/token` requests using the old secret fail.

Only available for `web` and `m2m` clients. SPA and native clients use PKCE and have no secret to rotate.

Requires an admin bearer token with the `applications:write` scope.

<Warning>
The plaintext `client_secret` is only returned here. Save it to your secret manager before this response leaves your terminal.
</Warning>

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

## Response

<ResponseField name="application_id" type="string">
  Echo of the application ID.
</ResponseField>

<ResponseField name="client_secret" type="string">
  The new plaintext secret. Shown once.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_state` | The client is `spa` or `native` and has no secret. |
| 404 | `not_found` | OAuth capability is not enabled for this application. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth/rotate-secret" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth/rotate-secret",
  { method: "POST", headers: { Authorization: `Bearer ${adminToken}` } }
);
const { client_secret } = await res.json();
```

</CodeGroup>
