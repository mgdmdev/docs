---
title: "Disable OAuth capability"
description: "Remove the OAuth capability row from an application."
api: "DELETE /api/applications/{id}/capabilities/oauth"
---

Deletes the `application_oauth` row. Existing sessions and refresh tokens issued to this client are revoked because every OAuth grant looks up the capability row on each request. The spine and other capabilities are untouched.

Requires an admin bearer token with the `applications:write` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` when the capability row was removed.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | OAuth capability is not enabled for this application. |

<CodeGroup>

```bash curl
curl -X DELETE "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
await fetch(
  "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth",
  { method: "DELETE", headers: { Authorization: `Bearer ${adminToken}` } }
);
```

</CodeGroup>
