---
title: "Update OAuth capability"
description: "Edit OAuth config fields in place — redirect URIs, scopes, token TTLs, auth methods, custom domains."
api: "PATCH /api/applications/{id}/capabilities/oauth"
---

Updates the existing `application_oauth` row. Send only the fields you want to change. To rotate the client secret use the dedicated [rotate endpoint](/api-reference/applications/rotate-oauth-secret); this endpoint never returns secrets.

Requires an admin bearer token with the `applications:write` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Application ID.
</ParamField>

## Body

<ParamField body="client_type" type="string">
  Change the client type. One of `web`, `spa`, `native`, `m2m`. Changing types does not invalidate existing tokens.
</ParamField>

<ParamField body="redirect_uris" type="string[]">
  Replaces the stored list.
</ParamField>

<ParamField body="post_logout_uris" type="string[]">
  Replaces the stored list.
</ParamField>

<ParamField body="allowed_scopes" type="string[]">
  Replaces the stored list.
</ParamField>

<ParamField body="cors_origins" type="string[]">
  Replaces the stored list.
</ParamField>

<ParamField body="access_token_ttl" type="integer">
  Access-token lifetime in seconds.
</ParamField>

<ParamField body="refresh_token_ttl" type="integer">
  Refresh-token lifetime in seconds.
</ParamField>

<ParamField body="refresh_token_rotation" type="boolean">
  Toggle refresh-token rotation on or off.
</ParamField>

<ParamField body="auth_methods" type="string[]">
  Replaces the stored list.
</ParamField>

<ParamField body="access_control" type="object">
  Replaces the stored JSON object, or pass `null` to clear it.
</ParamField>

<ParamField body="custom_subdomain" type="string">
  Set or clear (use `null`) the custom subdomain.
</ParamField>

<ParamField body="custom_domain" type="string">
  Set or clear (use `null`) the custom domain.
</ParamField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | Invalid `client_type` value. |
| 400 | `no_fields` | Body contained no recognized fields. |
| 404 | `not_found` | OAuth capability is not enabled for this application. |

<CodeGroup>

```bash curl
curl -X PATCH "https://auth.mgpass.net/api/applications/app_3news/capabilities/oauth" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "redirect_uris": [
      "https://3news.com/auth/callback",
      "https://staging.3news.com/auth/callback"
    ],
    "refresh_token_rotation": true
  }'
```
