---
title: "List Audit Logs"
api: "GET /api/audit"
---

Platform-wide audit records, newest first. Every privileged action writes one: role changes, suspensions, session revocations, capability edits, key rotations, redemption decisions.

Requires an admin bearer token. Filters combine with AND.

## Query parameters

<ParamField query="page" type="integer" default="1" />

<ParamField query="limit" type="integer" default="20">
  Values above 100 are reduced to 100.
</ParamField>

<ParamField query="event_type" type="string">
  Exact match, e.g. `role.assigned`, `user.sessions.revoked_all`, `balance.reconciled`.
</ParamField>

<ParamField query="actor_id" type="string">
  Who did it — usually an admin user id.
</ParamField>

<ParamField query="target_id" type="string">
  What it was done to — a user, Application or other record id.
</ParamField>

<ParamField query="from" type="integer">
  Unix epoch seconds, inclusive.
</ParamField>

<ParamField query="to" type="integer">
  Unix epoch seconds, inclusive.
</ParamField>

## Response

<ResponseField name="results" type="array">
  Audit records. `actor_name` and `target_name` are resolved where the referenced record still exists, and are `null` where it has since been deleted — the ids remain either way.
</ResponseField>

<ResponseField name="total" type="integer">
  Rows matching the filters, ignoring paging.
</ResponseField>

<Note>
  A record is never rewritten or removed, so the absence of a matching row is itself evidence. Read [Audit logs](/guides/audit-logs) for what is captured and for how long.
</Note>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |

<CodeGroup>

```bash curl
curl -G "https://auth.mgpass.net/api/audit" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  --data-urlencode "target_id=usr_abc123" \
  --data-urlencode "limit=100"
```

```typescript TypeScript
const params = new URLSearchParams({ target_id: userId, limit: "100" });
const res = await fetch(`https://auth.mgpass.net/api/audit?${params}`, {
  headers: { Authorization: `Bearer ${adminToken}` },
});
const { results, total } = await res.json();
```
