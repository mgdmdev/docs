---
title: "Update Role"
api: "PATCH /api/roles/{id}"
---

Updates a role. Only the fields you send are changed.

Requires an admin bearer token.

<Warning>
  Changing a role's scopes does not reissue tokens. Everyone holding it keeps their current scopes until their access token expires.
</Warning>

## Path parameters

<ParamField path="id" type="string" required />

## Body

<ParamField body="id" type="string" />

<ParamField body="name" type="string" />

<ParamField body="description" type="string" />

<ParamField body="type" type="string">
  `user` roles are assigned to people; `m2m` roles to machine clients. One of `user`, `m2m`.
</ParamField>

<ParamField body="is_default" type="boolean">
  True when the role is granted automatically to new users.
</ParamField>

<ParamField body="scopes" type="array" />

<ParamField body="created_at" type="integer">
  Unix epoch seconds.
</ParamField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | No fields to update. |
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `invalid_request` | No role with that id. |
