---
title: "Delete Role"
api: "DELETE /api/roles/{id}"
---

Deletes a role. Assignments to it are removed with it.

Requires an admin bearer token.

<Warning>
  Users holding the role lose its scopes, but not until their current access token expires.
</Warning>

## Path parameters

<ParamField path="id" type="string" required />

## Response

Deleted.

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `invalid_request` | No role with that id. |
