---
title: "Verify MFA Setup"
api: "POST /api/account/mfa/verify"
---

Completes multi-factor authentication enrollment by verifying the first TOTP code generated by the authenticator app.

When verification succeeds, TOTP MFA is permanently activated on the user's account, 8 single-use recovery codes are generated and returned, and a confirmation email is dispatched.

Requires an OAuth access token for the user.

## Body

<ParamField body="code" type="string" required>
  The current 6-digit code displayed in the authenticator app.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` once MFA verification succeeds.
</ResponseField>

<ResponseField name="recovery_codes" type="array">
  A list of 8 single-use recovery codes to use if the authenticator device is inaccessible.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `not_setup` | MFA enrollment has not been initiated via `POST /api/account/mfa/setup`. |
| 400 | `already_verified` | MFA is already active and verified on this account. |
| 400 | `invalid_code` | The submitted verification code is incorrect or expired. |
| 401 | `unauthorized` | Missing or invalid user token. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/account/mfa/verify" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "code": "583920" }'
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/account/mfa/verify", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ code: "583920" }),
});
const { success, recovery_codes } = await res.json();
```
