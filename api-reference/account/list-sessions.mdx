---
title: "List Own Sessions"
api: "GET /api/account/sessions"
---

Every device the user is currently signed in on, with the Application each session belongs to. This is what backs a "where you are signed in" screen.

Requires an OAuth access token for the user.

## Response

An array of sessions, one per live sign-in.

<ResponseField name="id" type="string" />

<ResponseField name="device_info" type="object">
  Device details recorded at sign-in, returned parsed.
</ResponseField>

<ResponseField name="ip_address" type="string" />

<ResponseField name="client_name" type="string">
  Display name of the Application the session belongs to.
</ResponseField>

<ResponseField name="client_logo_url" type="string" />

<ResponseField name="last_active_at" type="integer">
  Unix epoch seconds.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Unix epoch seconds.
</ResponseField>

<Tip>
  Pair this with [revoke a session](/api-reference/account/revoke-session) so a user who spots an unfamiliar device can end it themselves.
</Tip>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid access token. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/account/sessions" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/account/sessions", {
  headers: { Authorization: `Bearer ${accessToken}` },
});
const data = await res.json();
```

</CodeGroup>
