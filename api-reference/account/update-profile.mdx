---
title: "Update Own Profile"
api: "PATCH /api/account/profile"
---

Updates the signed-in user's own profile. Only the fields you send are changed; omit a field to leave it alone.

Requires an OAuth access token for the user.

<Note>
  Changing `email` or `phone` does not mark it verified. Verification is a separate flow, and the old address keeps working until the new one is confirmed.
</Note>
