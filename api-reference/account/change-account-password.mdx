---
title: "Change Account Password"
api: "POST /api/account/password"
---

Changes the password for the signed-in user account. The user must already have a password set; accounts that sign in exclusively via social identity cannot change their password with this endpoint. When successful, active sessions remain intact and a confirmation email is dispatched.

Requires an OAuth access token for the user.

## Body

<ParamField body="current_password" type="string" required>
  The account's existing password.
</ParamField>

<ParamField body="new_password" type="string" required>
  The new password. Must meet length and complexity requirements and pass breach checks.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` once the password has been updated.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | The account has no existing password set (e.g. social login only). |
| 400 | `invalid_password` | `current_password` does not match the account's current password. |
| 400 | `weak_password` | `new_password` failed complexity rules or appeared in breached password datasets. |
| 401 | `unauthorized` | Missing or invalid user token. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/account/password" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "current_password": "OldPassword123!",
    "new_password": "NewSecurePassword456!"
  }'
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/account/password", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    current_password: "OldPassword123!",
    new_password: "NewSecurePassword456!",
  }),
});
const data = await res.json();
```
