---
title: "Get Account Activity"
api: "GET /api/account/activity"
---

Returns a paginated log of recent activity on the signed-in account, newest first. Entries record sign-in attempts, password updates, MFA changes, and session management actions.

Requires an OAuth access token for the user.

## Query parameters

<ParamField query="page" type="integer" default="1">
  1-indexed page number.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of entries per page. Clamped to a maximum of 100.
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of activity log entries. Each entry includes `id`, `event_type`, `target_type`, `target_id`, `ip_address`, `user_agent`, `metadata`, and `created_at`.
</ResponseField>

<ResponseField name="total" type="integer">
  Total count of audit log entries for this account.
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number.
</ResponseField>

<ResponseField name="limit" type="integer">
  Entries limit applied for this query.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional records exist past the current page.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid user token. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/account/activity?page=1&limit=20" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/account/activity?page=1&limit=20", {
  headers: { Authorization: `Bearer ${accessToken}` },
});
const { data, total, page, limit, has_more } = await res.json();
```

</CodeGroup>
