---
title: "List Linked Social Accounts"
api: "GET /api/account/identities"
---

The social accounts the signed-in user has linked, newest first. Backs the "connected accounts" section of an account screen.

Requires an OAuth access token for the user.

## Response

An array of linked identities.

<ResponseField name="id" type="string" />

<ResponseField name="provider" type="string" />

<ResponseField name="provider_user_id" type="string">
  The user's id at that provider. Stable across sign-ins.
</ResponseField>

<ResponseField name="profile_data" type="object">
  The provider profile captured at link time, returned parsed. An empty object when none was stored.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Unix epoch seconds.
</ResponseField>

<Tip>
  Match on `provider_user_id`, not on the email. A user can change their email at the provider; the id stays put.
</Tip>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid access token. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/account/identities" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/account/identities", {
  headers: { Authorization: `Bearer ${accessToken}` },
});
const data = await res.json();
```

</CodeGroup>
