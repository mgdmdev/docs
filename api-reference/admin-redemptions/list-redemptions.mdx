---
title: "List Redemptions"
api: "GET /api/rewards/redemptions"
---

Every redemption across all users and all three types — catalog, cashback and order — newest first, with the holder's name and email joined in.

Requires an admin bearer token. Filters combine with AND.

## Query parameters

<ParamField query="page" type="integer" default="1" />

<ParamField query="limit" type="integer" default="20">
  Values above 100 are reduced to 100.
</ParamField>

<ParamField query="status" type="string">
  One of `pending`, `processing`, `completed`, `failed`, `cancelled`.
</ParamField>

<ParamField query="type" type="string">
  One of `catalog`, `cashback`, `partner_order`.
</ParamField>

<ParamField query="q" type="string">
  An exact user email address. An address matching no user returns an empty page rather than an error.
</ParamField>

<ParamField query="from" type="integer">
  Unix epoch seconds, inclusive.
</ParamField>

<ParamField query="to" type="integer">
  Unix epoch seconds, inclusive.
</ParamField>

## Response

<ResponseField name="results" type="array">
  Redemptions. Which fields carry values depends on the type — `cashback_amount`, `phone_number` and `network` on cashback rows; `order_reference`, `order_amount` and `value_amount` on [order redemptions](/guides/order-redemption); `reward_id` on catalog rows.
</ResponseField>

<ResponseField name="total" type="integer">
  Rows matching the filters, ignoring paging.
</ResponseField>

<Tip>
  Filter on `status=pending` with `type=partner_order` to find reservations that were never settled. They release themselves at `expires_at`, but a growing queue points at an integration that is not calling commit or void.
</Tip>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |

<CodeGroup>

```bash curl
curl -G "https://auth.mgpass.net/api/rewards/redemptions" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  --data-urlencode "status=pending" \
  --data-urlencode "type=cashback"
```

```typescript TypeScript
const params = new URLSearchParams({ status: "pending", type: "cashback" });
const res = await fetch(
  `https://auth.mgpass.net/api/rewards/redemptions?${params}`,
  { headers: { Authorization: `Bearer ${adminToken}` } },
);
const { results, total } = await res.json();
```
