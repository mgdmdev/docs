---
title: "Delete promo code"
description: "Deactivate a promo code (soft delete)."
api: "DELETE /api/subscriptions/promo-codes/:id"
---

Soft-deletes the code by setting `active = 0`. The row stays in place because `promo_redemptions` rows reference it via foreign key — hard-deleting would break the historical record of who got what discount. Writes a `subscriptions.promo_deactivated` audit row.

Requires an admin bearer token with the `subscriptions:write` scope.

## Path parameters

<ParamField path="id" type="string" required>Promo code ID.</ParamField>

## Response

`200 OK`.

<ResponseField name="success" type="boolean">Always `true`.</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Promo code doesn't exist. |

<CodeGroup>

```bash curl
curl -X DELETE "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
await fetch(
  "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz",

  }

```
