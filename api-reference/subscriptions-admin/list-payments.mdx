---
title: "List payments"
description: "Payments recorded against a single subscription."
api: "GET /api/subscriptions/:id/payments"
---

Returns every `subscription_payments` row for the subscription, including charges, retries, and refunds.

Requires an admin bearer token with the `subscriptions:read` scope.

## Path parameters

<ParamField path="id" type="string" required>Subscription ID, e.g. `sub_xyz`.</ParamField>

## Response

<ResponseField name="results" type="array">
  Array of payment rows.
  <Expandable title="payment">
    <ResponseField name="id" type="string">Payment ID, e.g. `pi_xyz`.</ResponseField>
    <ResponseField name="subscription_id" type="string">Owning subscription.</ResponseField>
    <ResponseField name="user_id" type="string">Charged user.</ResponseField>
    <ResponseField name="amount" type="number">Minor units. Negative for refunds.</ResponseField>
    <ResponseField name="currency" type="string">`GHS` or `USD`.</ResponseField>
    <ResponseField name="payment_provider" type="string">`paystack` or `hubtel`.</ResponseField>
    <ResponseField name="status" type="string">`succeeded | failed | refunded | pending`.</ResponseField>
    <ResponseField name="payment_type" type="string">`charge | refund | retry`.</ResponseField>
    <ResponseField name="failure_reason" type="string">For `failed` rows, the provider error message.</ResponseField>
    <ResponseField name="provider_reference" type="string">Provider transaction reference.</ResponseField>
    <ResponseField name="created_at" type="number">Unix epoch seconds.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">Number of payments returned.</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Subscription doesn't exist. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/subscriptions/sub_xyz/payments" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/subscriptions/sub_xyz/payments",
  { headers: { Authorization: `Bearer ${adminToken}` } }
);
const { results } = await res.json();
```

</CodeGroup>
