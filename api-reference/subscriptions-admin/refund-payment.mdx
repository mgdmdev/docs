---
title: "Refund payment"
description: "Record a refund against a subscription and cancel it immediately."
api: "POST /api/subscriptions/:id/refund"
---

Records a negative-amount `subscription_payments` row (`payment_type=refund`, `status=refunded`) and cancels the subscription immediately. Writes a `subscriptions.refund_issued` audit row.

The refund is recorded in mgPass — actually issuing money back to the customer's card happens at Paystack. Use this endpoint after you've issued the Paystack refund (or in parallel), so mgPass's books and the customer's entitlements line up.

Requires an admin bearer token with the `subscriptions:write` scope.

## Path parameters

<ParamField path="id" type="string" required>Subscription ID.</ParamField>

## Body

<ParamField body="amount" type="number" required>
  Refund amount in minor units (pesewas/cents). Must be positive.
</ParamField>

<ParamField body="reason" type="string">
  Free-form reason captured on the payment row's `failure_reason` column and in the audit log.
</ParamField>

## Response

`200 OK`.

<ResponseField name="success" type="boolean">Always `true`.</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `invalid_request` | `amount` is missing or `<= 0`. |
| 404 | `not_found` | Subscription doesn't exist. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/subscriptions/sub_xyz/refund" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "amount": 2500, "reason": "Duplicate charge" }'
```

```typescript TypeScript
await fetch("https://auth.mgpass.net/api/subscriptions/sub_xyz/refund", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${adminToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ amount: 2500, reason: "Duplicate charge" }),
});
```
