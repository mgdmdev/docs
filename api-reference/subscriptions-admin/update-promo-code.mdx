---
title: "Update promo code"
description: "Patch a promo code from the admin console."
api: "PATCH /api/subscriptions/promo-codes/:id"
---

Partially updates a promo code. Writes a `subscriptions.promo_updated` audit row with the list of changed fields.

Requires an admin bearer token with the `subscriptions:write` scope.

## Path parameters

<ParamField path="id" type="string" required>Promo code ID.</ParamField>

## Body

All fields optional.

<ParamField body="code" type="string">User-facing code.</ParamField>
<ParamField body="discount_type" type="string">`percent` or `fixed_amount`.</ParamField>
<ParamField body="discount_value" type="number">Percentage, or minor units.</ParamField>
<ParamField body="duration" type="string">`once | repeating | forever`.</ParamField>
<ParamField body="duration_months" type="number">Number of months.</ParamField>
<ParamField body="max_redemptions" type="number">Global cap.</ParamField>
<ParamField body="per_user_limit" type="number">Per-user cap.</ParamField>
<ParamField body="application_id" type="string">Reassign to a different application or unset (pass `null` via JSON).</ParamField>
<ParamField body="plan_ids" type="string[]">Plan restriction array.</ParamField>
<ParamField body="expires_at" type="number">Unix epoch seconds.</ParamField>
<ParamField body="active" type="boolean">Availability flag.</ParamField>

## Response

`200 OK`.

<ResponseField name="success" type="boolean">Always `true`.</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 400 | `no_fields` | Body had no recognized fields. |
| 404 | `not_found` | Promo code doesn't exist. |

<CodeGroup>

```bash curl
curl -X PATCH "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "max_redemptions": 2000 }'
```

```typescript TypeScript
await fetch(
  "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz",
  {
    method: "PATCH",
    headers: {
      Authorization: `Bearer ${adminToken}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ max_redemptions: 2000 }),
  }
);
```
