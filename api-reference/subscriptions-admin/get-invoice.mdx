---
title: "Get invoice"
description: "Fetch a single invoice by ID."
api: "GET /api/subscriptions/invoices/:id"
---

Returns one invoice row.

Requires an admin bearer token with the `subscriptions:read` scope.

## Path parameters

<ParamField path="id" type="string" required>Invoice ID, e.g. `inv_xyz`.</ParamField>

## Response

The full invoice row. See [List invoices](/api-reference/subscriptions-admin/list-invoices) for field definitions.

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Invoice doesn't exist. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/subscriptions/invoices/inv_xyz" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/subscriptions/invoices/inv_xyz",
  { headers: { Authorization: `Bearer ${adminToken}` } }
);
const invoice = await res.json();
```

</CodeGroup>
