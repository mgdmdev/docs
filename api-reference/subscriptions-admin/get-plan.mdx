---
title: "Get plan"
description: "Fetch a single subscription plan by ID."
api: "GET /api/subscriptions/plans/:id"
---

Returns one plan row. No application scoping — admin tokens can read any plan.

Requires an admin bearer token with the `subscriptions:read` scope.

## Path parameters

<ParamField path="id" type="string" required>
  Plan ID, e.g. `plan_pro`.
</ParamField>

## Response

The full plan row. See [`GET /v1/plans`](/api-reference/subscriptions-tenant/list-plans) for field definitions.

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Plan doesn't exist. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/subscriptions/plans/plan_pro" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/subscriptions/plans/plan_pro",
  { headers: { Authorization: `Bearer ${adminToken}` } }
);
const plan = await res.json();
```

</CodeGroup>
