---
title: "Get subscription"
description: "Fetch a single subscription by ID."
api: "GET /api/subscriptions/:id"
---

Returns the full subscription row, regardless of which application owns it.

Requires an admin bearer token with the `subscriptions:read` scope.

## Path parameters

<ParamField path="id" type="string" required>Subscription ID, e.g. `sub_xyz`.</ParamField>

## Response

The full subscription row. See [`GET /v1/subscriptions/:id`](/api-reference/subscriptions-tenant/get-subscription) for field definitions.

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Subscription doesn't exist. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/subscriptions/sub_xyz" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch("https://auth.mgpass.net/api/subscriptions/sub_xyz", {
  headers: { Authorization: `Bearer ${adminToken}` },
});
const subscription = await res.json();
```

</CodeGroup>
