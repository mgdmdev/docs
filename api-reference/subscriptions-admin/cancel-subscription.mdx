---
title: "Cancel subscription"
description: "Cancel a subscription from the admin console."
api: "POST /api/subscriptions/:id/cancel"
---

Admin-side cancellation. Same semantics as the tenant [`POST /v1/subscriptions/:id/cancel`](/api-reference/subscriptions-tenant/cancel-subscription): default cancels at period end, `immediate: true` cancels right now. The cancelling actor is recorded as `admin:<user_id>` in the audit log.

Requires an admin bearer token with the `subscriptions:write` scope.

## Path parameters

<ParamField path="id" type="string" required>Subscription ID.</ParamField>

## Body

<ParamField body="immediate" type="boolean" default="false">
  When `true`, cancels immediately. When `false`, queues cancellation at `current_period_end`.
</ParamField>

## Response

`200 OK`.

<ResponseField name="success" type="boolean">Always `true`.</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Subscription doesn't exist. |

<CodeGroup>

```bash curl
curl -X POST "https://auth.mgpass.net/api/subscriptions/sub_xyz/cancel" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "immediate": true }'
```

```typescript TypeScript
await fetch("https://auth.mgpass.net/api/subscriptions/sub_xyz/cancel", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${adminToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ immediate: true }),
});
```

</CodeGroup>
