---
title: "Get promo code"
description: "Fetch a single promo code by ID."
api: "GET /api/subscriptions/promo-codes/:id"
---

Returns one promo code row.

Requires an admin bearer token with the `subscriptions:read` scope.

## Path parameters

<ParamField path="id" type="string" required>Promo code ID.</ParamField>

## Response

The full promo code row. See [List promo codes](/api-reference/subscriptions-tenant/list-promo-codes) for field definitions.

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Promo code doesn't exist. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/subscriptions/promo-codes/promo_xyz",
  { headers: { Authorization: `Bearer ${adminToken}` } }
);
const promo = await res.json();
```

</CodeGroup>
