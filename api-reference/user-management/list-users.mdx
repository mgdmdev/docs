---
title: "List Users"
api: "GET /api/users"
---

Every user on the platform, page by page. Soft-deleted accounts are excluded.

Requires an admin bearer token.

<Note>
  Timestamps here are ISO 8601 strings, not the epoch seconds most of the API uses. `last_sign_in_at` falls back to the newest session when the column was never stamped, so it is populated for accounts that pre-date the column.
</Note>
