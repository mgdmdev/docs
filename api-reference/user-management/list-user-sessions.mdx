---
title: "List User Sessions"
api: "GET /api/users/{id}/sessions"
---

Every live session for one user, with the Application each belongs to. Use it to see where someone is signed in before revoking.

Requires an admin bearer token.

## Path parameters

<ParamField path="id" type="string" required>
  The user id.
</ParamField>

## Response

An array of sessions.

<ResponseField name="id" type="string">
  Session id. Pass it to the single-session revoke endpoint.
</ResponseField>

<ResponseField name="client_id" type="string">
  The `application_id` the session was created for. The field is named `client_id` for parity with the account portal's sessions contract — the value is an Application id.
</ResponseField>

<ResponseField name="client_name" type="string">
  Display name of that Application.
</ResponseField>

<ResponseField name="client_logo_url" type="string">
  Application logo, or `null`.
</ResponseField>

<ResponseField name="device_info" type="object">
  Parsed device details recorded at sign-in, or `null` when none were captured.
</ResponseField>

<ResponseField name="ip_address" type="string">
  IP the session was last seen from, or `null`.
</ResponseField>

<ResponseField name="last_active_at" type="integer">
  Unix epoch seconds.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Unix epoch seconds.
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/users/usr_abc123/sessions" \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

```typescript TypeScript
const res = await fetch(`https://auth.mgpass.net/api/users/${userId}/sessions`, {
  headers: { Authorization: `Bearer ${adminToken}` },
});
const sessions = await res.json();
```

</CodeGroup>
