---
title: "Suspend User"
api: "POST /api/users/{id}/suspend"
---

Blocks a user from signing in and records why. Lift it with [unsuspend](/api-reference/user-management/unsuspend-user).

Requires an admin bearer token.

<Note>
  Suspension stops new sign-ins. Tokens already issued keep working until they expire — [revoke every session](/api-reference/user-management/revoke-all-sessions) as well if the block has to take effect now.
</Note>
