---
title: "Delete Rule"
api: "DELETE /api/rewards/rules/{id}"
---

Deletes a points rule. Points already awarded by it stay in the ledger.

Requires an admin bearer token.

<Tip>
  Setting `is_active` to `0` with [update](/api-reference/admin-rules/update-rule) stops the rule without losing its definition, which is usually what you want.
</Tip>

## Path parameters

<ParamField path="id" type="string" required />

## Response

Deleted.

## Errors

| Status | Code | When |
|--------|------|------|
| 401 | `unauthorized` | Missing or invalid admin token. |
| 404 | `not_found` | No rule with that id. |
