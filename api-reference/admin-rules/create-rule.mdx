---
title: "Create Rule"
api: "POST /api/rewards/rules"
---

Defines how an event earns points. `points_type: flat` awards `points` once per event; `per_unit` multiplies `points` by the metadata field named in `unit_field`.

Requires an admin bearer token.

<Warning>
  A `per_unit` rule with no `unit_field`, or naming a field the event does not carry, awards nothing. Publish a test event and check the ledger before relying on it.
</Warning>

<Note>
  Leaving `platform` null applies the rule to every Application. That is rarely what you want for a purchase rule — one Application's definition of `amount` is not another's.
</Note>

## Body

<ParamField body="id" type="string" />

<ParamField body="platform" type="string">
  The Application the rule applies to, by name. Null matches every Application.
</ParamField>

<ParamField body="event_type" type="string" />

<ParamField body="tier" type="string">
  Restrict the rule to one tier. Null applies it to all.
</ParamField>

<ParamField body="points" type="integer">
  Points awarded
</ParamField>

<ParamField body="points_type" type="string">
  One of `flat`, `per_unit`.
</ParamField>

<ParamField body="unit_field" type="string">
  The metadata field multiplied by `points` when `points_type` is `per_unit`, e.g. `amount`.
</ParamField>

<ParamField body="daily_cap" type="integer" />

<ParamField body="monthly_cap" type="integer" />

<ParamField body="is_active" type="boolean" />

<ParamField body="version" type="string">
  Stamped onto every ledger entry the rule produces.
</ParamField>

<ParamField body="created_at" type="integer">
  Unix epoch seconds.
</ParamField>
