---
title: "List subscriptions"
description: "Paginated list of subscriptions on the calling application."
api: "GET /v1/subscriptions"
---

Returns subscriptions owned by the application keyed via `X-API-Key`. Filter by user or status. Results are paginated.

Requires the `X-API-Key` header with a Subscriptions capability key.

## Query parameters

<ParamField query="user_id" type="string">Filter to a single user.</ParamField>
<ParamField query="status" type="string">`active | trialing | past_due | cancelled | expired | unpaid`.</ParamField>
<ParamField query="page" type="number" default="1">1-indexed page.</ParamField>
<ParamField query="limit" type="number" default="20">Page size, max `100`.</ParamField>

## Response

<ResponseField name="results" type="array">
  Array of subscription rows.
  <Expandable title="subscription">
    <ResponseField name="id" type="string">Subscription ID, e.g. `sub_xyz`.</ResponseField>
    <ResponseField name="user_id" type="string">Owning user.</ResponseField>
    <ResponseField name="plan_id" type="string">Plan ID.</ResponseField>
    <ResponseField name="application_id" type="string">Owning application.</ResponseField>
    <ResponseField name="status" type="string">Lifecycle state.</ResponseField>
    <ResponseField name="current_period_start" type="number">Unix epoch seconds.</ResponseField>
    <ResponseField name="current_period_end" type="number">Unix epoch seconds.</ResponseField>
    <ResponseField name="trial_end" type="number">Unix epoch seconds if in trial.</ResponseField>
    <ResponseField name="cancel_at_period_end" type="number">`1` if cancellation is queued at period end.</ResponseField>
    <ResponseField name="cancelled_at" type="number">Unix epoch seconds when cancelled.</ResponseField>
    <ResponseField name="payment_provider" type="string">`paystack` or `hubtel`.</ResponseField>
    <ResponseField name="promo_code_id" type="string">Attached promo code.</ResponseField>
    <ResponseField name="sponsored" type="number">`1` if sponsored.</ResponseField>
    <ResponseField name="metadata" type="string">JSON-encoded metadata.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">Total matching rows across all pages.</ResponseField>

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/v1/subscriptions?status=active&page=1&limit=50" \
  -H "X-API-Key: $SUBS_API_KEY"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/v1/subscriptions?status=active&page=1&limit=50",
  { headers: { "X-API-Key": subsApiKey } }
);
const { results, total } = await res.json();
```
