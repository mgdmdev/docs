---
title: "Get notification"
description: "Full detail view of one notification including per-surface delivery records."
api: "GET /api/account/notifications/:id"
---

Returns one notification belonging to the calling user, plus its per-surface `deliveries` sub-resource so the UI can show exactly which surfaces fired, when each delivered, and any failure reasons.

Requires an OAuth Bearer access token. The notification must belong to the calling user — otherwise a `404` is returned (no leak of foreign IDs).

## Path parameters

<ParamField path="id" type="string" required>Notification ID.</ParamField>

## Response

<ResponseField name="notification" type="object">
  Same shape as a row in [List my notifications](/api-reference/notifications-account/list-notifications) — includes `data` (decoded), `surfaces` (decoded), `subject`, `preview_text`, `read`, `read_at`, `archived_at`, `status`, `created_at`.
</ResponseField>

<ResponseField name="deliveries" type="array">
  One row per delivery surface attempted for this notification. Useful for showing the user "delivered to email at 14:02, SMS failed: invalid number."
  <Expandable title="delivery">
    <ResponseField name="id" type="string">Delivery row ID.</ResponseField>
    <ResponseField name="notification_id" type="string">Parent notification ID.</ResponseField>
    <ResponseField name="surface" type="string">`email | sms | webhook | push`.</ResponseField>
    <ResponseField name="status" type="string">`pending | delivered | failed`.</ResponseField>
    <ResponseField name="provider_reference" type="string">Upstream message ID from SES / Hubtel, or `null`.</ResponseField>
    <ResponseField name="error_message" type="string">Failure reason if `status = failed`.</ResponseField>
    <ResponseField name="attempt_count" type="number">Number of attempts so far.</ResponseField>
    <ResponseField name="next_retry_at" type="number">Unix epoch seconds of the next scheduled retry, or `null`.</ResponseField>
    <ResponseField name="delivered_at" type="number">Unix epoch seconds of successful delivery, or `null`.</ResponseField>
    <ResponseField name="created_at" type="number">Unix epoch seconds.</ResponseField>
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
|--------|------|------|
| 404 | `not_found` | Notification doesn't exist, or doesn't belong to the calling user. |

<CodeGroup>

```bash curl
curl "https://auth.mgpass.net/api/account/notifications/notif_xyz" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

```typescript TypeScript
const res = await fetch(
  "https://auth.mgpass.net/api/account/notifications/notif_xyz",
  { headers: { Authorization: `Bearer ${userAccessToken}` } }
);
const { notification, deliveries } = await res.json();
```

</CodeGroup>
