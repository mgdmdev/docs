---
title: "Token Exchange"
api: "POST /token"
---

The OAuth 2.0 token endpoint: exchanges an authorization code for tokens, and refreshes them later. See [OAuth flows](/guides/oauth-flows) for the full sequence.

Confidential clients authenticate with their `client_secret`, over HTTP Basic or in the body. Public clients send a PKCE verifier instead.

<Warning>
  The authorization code grant authenticates the client. A confidential Application must send a valid `client_secret`; a public one must send a valid PKCE `code_verifier`. Neither is optional.
</Warning>

<Note>
  Refresh tokens rotate: each refresh returns a new one and retires the old. Reusing a retired token revokes the whole family, with a ten-second grace window so a racing retry is not punished.
</Note>
